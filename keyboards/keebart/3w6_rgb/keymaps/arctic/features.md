# Basic Principles
- Least hand motion possible for most common operations
- Equal usage of both hands
- Reduce usage of pinkies as much as possible
- Where it makes sense, use combos instead of tap-hold
- minimise number of layers to reduce complexits
# Must have
- Perform this using only the left hand:
    - cut, copy, paste, save, find
    - typing numbers
- both alt and alt-gr must be available
- makros for word left, word right, delete work, backspace word
- automatically configure to current OS and adjust keycode mappings accordingly
